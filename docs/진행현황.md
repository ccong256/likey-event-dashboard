# LIKEY 이벤트 대시보드 진행 현황

## 완료된 화면

### 1. 이벤트 목록 (`/events`)
**파일**: `app/events/page.tsx`

**기능**:
- 이벤트 목록 테이블 (이름, 기간, 국가, 매출, 크리에이터 수, 상태)
- 통계 카드 (전체/진행중/종료됨)
- 필터 (전체/진행중/종료됨)
- 새 이벤트 등록 버튼
- 각 이벤트별 업로드/상세 버튼

**데이터**:
- 현재 더미 데이터 (Supabase 연동 예정)

---

### 2. 이벤트 등록 (`/events/new`)
**파일**: `app/events/new/page.tsx`

**기능**:
- 이벤트명 입력 (필수)
- 설명 입력 (선택)
- 기간 설정 (시작일/종료일, 필수)
- 대상 국가 선택 (복수 선택 가능)
- 폼 유효성 검사
- 이벤트 기간 자동 계산 표시

**데이터**:
- 현재 콘솔 출력만 (Supabase 연동 예정)

---

### 3. 모니터링 대시보드 (`/`)
**파일**: `app/page.tsx`

**기능**:
- KPI 카드 4개: 총 매출, 선물 수량, 참여 유저 수, 선물 받은 크리에이터
- 직전 기간 대비 증감률 표시
- TOP 5 / TOP 10 크리에이터 매출 바 차트
- TOP 5 / TOP 10 매출 점유율 파이 차트
- 전체 크리에이터 랭킹 테이블 (정렬 기능 포함)
- 페이지네이션 (10개씩)
- 날짜 직접 입력 기능

**정렬 기능**:
- 순위, 골드/매출, 선물 수량, 참여 유저 컬럼 클릭으로 정렬
- 내림차순: 1등, 2등, 3등...
- 오름차순: 40등, 39등, 38등... (역순)

**데이터**:
- 현재 하드코딩된 샘플 데이터 (40명 크리에이터)
- 1골드 = 100원 매출 변환

---

### 5. 로그인 (`/login`)
**파일**: `app/login/page.tsx`

**기능**:
- 비밀번호 입력
- 로그인 성공 시 이벤트 목록으로 이동
- 기본 비밀번호: `likey2025` (환경변수로 변경 가능)

---

### 6. 저장된 대시보드 목록 (`/events/[id]`)
**파일**: `app/events/[id]/page.tsx`

**기능**:
- 이벤트 정보 표시 (이름, 기간, 상태)
- 저장된 대시보드 목록 테이블
- 각 대시보드: 이름, 유형, 데이터 기간, 매출, 선물 수, 저장일시
- 새 데이터 업로드 버튼

**데이터**:
- 현재 더미 데이터 (Supabase 연동 예정)

---

### 7. CSV 업로드 (`/events/[id]/upload`)
**파일**: `app/events/[id]/upload/page.tsx`

**기능**:
- 이벤트 기간 데이터 업로드 (필수)
- 직전 기간 데이터 업로드 (선택)
- 드래그 앤 드롭 또는 파일 선택
- CSV 파싱 및 검증
- 업로드 후 요약 통계 표시 (크리에이터 수, 총 매출, 선물 수량, 참여 유저)
- 두 기간 모두 업로드 시 성과 비교 미리보기
- 데이터 미리보기 테이블 (상위 20개)

**CSV 컬럼 매핑**:
- Uid, NickName, username, country
- 골드 수량, 선물 수량, 선물을 보낸 유저 수, 선물 보낸 유저들 정보

---

## 미완료 화면

| 화면 | 경로 | 설명 |
|-----|------|------|
| 저장된 대시보드 목록 | `/events/[id]` | 이벤트별 저장된 대시보드 목록 |
| 성과 분석 | `/events/[id]/report` | AI 인사이트 포함 (배포 후 추가) |
| 이벤트 비교 | `/events/compare` | 복수 이벤트 비교 (배포 후 추가) |

---

## 화면 흐름

```
로그인 → 이벤트 목록 → 이벤트 선택 → 저장된 대시보드 목록
                                          ├── 대시보드 선택 → 저장된 대시보드 보기
                                          └── 새로 업로드 → 대시보드 확인 → 저장
```

---

## 기술 스택

- **Framework**: Next.js 14 (App Router)
- **UI**: Tailwind CSS + shadcn/ui
- **차트**: Recharts
- **CSV 파싱**: papaparse
- **상태 관리**: React useState
